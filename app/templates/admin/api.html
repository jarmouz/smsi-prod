Utilisation

Description OpenAPI

Adresse de l'inventaire : {{ base_url }}/api/v1/actifs. Filtres : role, categorie, classification, statut, criticite, cycle, reference, modifie_depuis, et pagination avec page et par_page (500 au maximum). Limite : 120 appels par minute et par jeton.

Un outil peut aussi pousser ses actifs, avec un jeton « Lecture et synchronisation » : POST /api/v1/actifs/synchronisation. Les besoins DIC+T, la classification, le propriétaire et les dépendances ne sont jamais modifiés. Pour GLPI, Intune, Entra ID, Azure ou AWS, utilisez les connecteurs.

curl
curl -H "Authorization: Bearer VOTRE_JETON" "{{ base_url }}/api/v1/actifs?role=support&cycle=fin_support"
PowerShell
Invoke-RestMethod -Uri "{{ base_url }}/api/v1/actifs?par_page=500" -Headers @{ Authorization = "Bearer VOTRE_JETON" }
Power BI ou Excel (Power Query)
let r = Json.Document(Web.Contents("{{ base_url }}/api/v1/actifs", [Headers=[Authorization="Bearer VOTRE_JETON"], Query=[par_page="500"]]))
in Table.FromRecords(r[donnees])
